# 音标示范修订（0.4.1）

## 当前交付范围与未完成项

已移除旧版 48 项不适合单音教学的示范、整词回退和对应的素材生成脚本。48 项教学内容、分类、口型提示和例词仍保留。**尚未获得可随项目分发并完成教学审核的整套英式真人单音录音，内置合格录音目前为 0 项。** 本次不宣称完成标准音源替换。

音标页只播放两类明确来源：项目审核后登记的固定录音，或家长在本机选择的录音。后者注明尚未经过教学审核。音标播放不调用 Kokoro、eSpeak 或系统 TTS，不跟随故事朗读语速。

## 家庭使用

1. 打开「设置 → 声音 → 音标教学录音」。
2. 选择目标音标，填写讲者或教材名称，选择自己录制或获准使用的英式教学音频。
3. 完整试听，确认读的是目标音，再点击「采用这段示范」。
4. 返回音标页，点击对应音标播放。录音保存在当前设备的 IndexedDB；Android 安装包可以离线播放。

支持 WAV、MP3、OGG、M4A、WebM（具体解码能力以设备为准），每项最多 2 MB、0.08～8 秒。应用检查格式、时长和是否近乎静音，**不自动认证发音标准**。同一音标重新保存会替换该项本机录音；也可以单项移除。导入文件不上传，不包含在文章和练习记录导出中，请保留原文件。清除站点/应用数据、卸载应用或更换网页域名，可能使本机录音不可用。

## 录制或选材要求

- 沿用传统英式教学表：44 个音素加 /ts dz tr dr/ 四组辅音。
- 尽量使用同一位熟悉英式发音教学的讲者，避免混用通用基准元音、英式与美式词例。
- 每个文件示范目标声音一次，保留必要的起音、爆破与收尾。辅音不要额外添加 /ə/ 或 /ɑ/；辅音组合直接连读，不加入单词和讲解。
- 长短元音按英语实际音质和时长示范，不把同一通用 IPA 元音机械拉长作为长元音。
- /ʊə/ 等传统项目存在口音变化，需要教师核对目标读法。英语 /r/ 使用英语近音，不能采用颤音录音。
- 音量舒适，无背景音乐、削波和过度降噪。不得剪掉爆破音的有效部分来追求时长一致。
- 至少逐项核听目标音、额外音节、口音一致性及录音质量。单词 ASR 成功、音频解码通过、声学相似度高都不能代替此项审核。

## 随应用打包

将通过审核的文件放到 `public/sounds/approved/<id>.mp3`（也可 WAV/OGG），更新 `public/sounds/catalog.v2.json` 的 `entries`。`id` 对应 `src/learning.ts` 的音标 ID。

```json
{
  "schemaVersion": 2,
  "accent": "en-GB",
  "entries": {
    "ae": {
      "path": "sounds/approved/ae.mp3",
      "kind": "isolated-human",
      "accent": "en-GB",
      "author": "实际讲者或权利人",
      "source": "https://实际来源页面",
      "license": "实际允许离线再分发的许可",
      "licenseUrl": "https://许可或授权记录页面",
      "sha256": "填写该音频实际的64位SHA256",
      "review": {
        "status": "accepted",
        "reviewer": "实际完成逐项核听的审核者",
        "date": "2026-09-09"
      }
    }
  }
}
```

以上为结构示例，不能直接当作已审核素材使用。未取得录音、授权或未完成核听的项目，不填入 `entries`。同时在 `public/sounds/ATTRIBUTION.md` 登记来源、署名、许可与处理方式。许可另有要求时附上相应文件。`npm test` 检查元数据、白名单路径和实际文件哈希；浏览器测试验证播放与异常路径。
