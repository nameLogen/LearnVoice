# 故事阅读 0.3

## 内容与数据

`ArticleReader.tsx` 是阅读入口。文章保留为纯文本，由 `articles.ts` 按换行分段、按英语句界拆句；超过 18 个空白分隔词或 300 字符的句子拆成小段。显示保留缩写、撇号、连字符和重复单词，不将输入作为 HTML 执行。

文章与已完成小句 ID 保存在 `voice-lab-articles-v1`，最近选择保存在 `voice-lab-selected-article`。最多 20 篇，每篇 30,000 字符。新增文章不改源码或重新打包。TXT 要求 UTF-8。JSON 导入检查数据结构和限制，为每篇分配新 ID，追加而不覆盖现有文章。存储失败会提示且不假装保存成功；删除需点击确认。清除网站/应用数据或卸载会清空本机文章，定期导出备份。

## 离线朗读

- Android：`OfflineSpeechPlugin.java` 经 Capacitor 调用系统 TextToSpeech，检测英语声音，排除需要网络或声明未安装的声音，每次播放重新检查。以 `UtteranceProgressListener` 完成回调驱动下一句。
- 网页：`offlineSpeech.ts` 仅列出、使用 `localService=true` 的英语声音。没有声音时禁用合成朗读；不选择系统默认声音作为兜底。
- 两端逐句串行播放，以实际结束事件推进高亮；支持语速、停止、换页停止、后台停止、超时退出。原音回放、真人示范、合成朗读互斥；开始录音前先停止示范。
- 现有英语单词示范仍使用捆绑真人录音；其他词使用设备离线合成。合成语音不称为真人或教学认证发音。
- 系统是否有引擎/语言包、声音品质因设备而异。本版未附带通用 TTS 模型，不承诺所有手机开箱即有离线英语声音。语言包安装可能需要联网，但后续文本朗读不调用在线服务。请在目标手机飞行模式下实际试听。
- 网页模型和词典来自同一静态站点；未实现 PWA 完整缓存。断网冷启动请使用含资源的 Android APK，不能把网页“本地计算”理解为网页已完整离线缓存。

## 单词测试

`dictionary.ts` 按需读取捆绑的原始 CMU 词典（固定 commit、SHA-256 见 `public/dictionary/README.md`），转成美式 IPA 音素序列。已有练习题的人工目标优先。未知词可以听合成、录音、回放，但禁用评分，未接入拼写推导模型。

多种词典读法同时列出并作为比较候选，尚未解决 `read` 等词的上下文读音选择。目标省略词典重音，重音不参与评分。模型的音素切分与宽式词典不一定完全一致，连音、卷舌元音等可能导致额外误差。

单词仍限制 5 秒，经真实 ONNX 音素识别和既有 `phone-distance-v1` 计算实验接近度。不是声学准确率，也不是把录音与合成声音直接相减。观察记录进入原有历史页，原始录音不导出。

## 段落跟读

选择段落后逐句或逐小段练习：先听、录音、回放、主动标记“这一句练好了”。每次最多 30 秒；到时明确提示自动停止。静音、过短和明显失真的录音不能标记完成。完成只表示进行过该次练习，不表示识别确认读对。

短句录音复用浏览器 AudioWorklet / Android AudioRecord；只扩展采集时长，ONNX 单次分析上限仍为 5 秒。段落录音不送给短词模型做伪精确评分。连续整段对齐、漏词定位、重音/节奏评分尚未实现。

## 验证

- 单元测试：分段和长文本边界、重复词/撇号保留、备份格式校验、源词典 SHA-256、超过十万词条、schwa 与重读元音区分、多读音及未知词。
- 桌面/手机浏览器：文章添加和 TXT 导入、词典真实读取、重开保留、纯文本渲染、备份回导、无本地声音时不调用远程声音、真人示范仍可播放。
- 浏览器 TTS 调用测试使用明确标注的接口模拟，因为 headless Chromium 没有安装 OS 声音；模拟验证播放顺序和取消，不代表真实 TTS 音质或真机离线测试。
- 子目录站点：实际麦克风采集管线（Chromium 的合成输入）、完成进度、任意词目标下的真实 WASM 模型推理。合成输入不用于声称发音评分准确。
- Android：APK 编译和 lint。没有连接手机时不能声称已做真机听感、耗时、飞行模式或儿童录音准确性验证。

建议首次真机验证：准备本地英语声音 → 开飞行模式 → 播放新粘贴文章 → 点未预设单词 → 跟读回放 → 开始本地分析 → 段落逐句跟读 → 关闭重开确认进度。
