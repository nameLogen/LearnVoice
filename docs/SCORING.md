# 真人示范与实验接近度（0.2）

14 个目标均内置真人参考音频，不调用系统朗读或在线 TTS。英语单词为美式英语，IPA 元音为单音；/s/、/ʃ/ 从公开授权示范中截取开头清辅音，避开后面的 /a/。`mā` 使用“妈妈”的词例，界面提醒只跟读第一个音；其他三声为独立音节。

逐文件作者、来源、许可、修改方式、哈希见 [音频署名](../public/references/ATTRIBUTION.md) 和 `public/references/catalog.json`。素材来自 Wikimedia Commons / Shtooka 的公开授权录音，不能声称已经过本项目教师审核或获得教材认证。衍生 /s/、/ʃ/ 片段按 CC BY-SA 3.0 分发，原素材许可继续适用于对应音频。

开始录音、换题、离开实验页面或切到后台时停止示范。示范与自己的回放互斥播放；失败会提示错误，不改用联网语音。

## 分数表示什么

`phone-distance-v1` 是**模型识别的音素序列与目标音素之间的接近度**，不是直接比较孩子与示范的声音，也不是发音准确率、标准发音概率或考试分数。当前仅英语有数字；拼音没有声调评测，暂不计分。

- 静音、太短、失真、无可用音素、未知音素不计分。任一标签置信度低于 0.2 或平均低于 0.35 也不计分；这些阈值尚未经过儿童样本校准。
- 对每个预设合法序列执行加权编辑距离对齐。同音代价 0，漏音/多音代价 1。
- 元音替换代价为 `0.25 + 0.45 × 高度差/6 + 0.2 × 前后差/4 + 0.1 × 圆唇差`；辅音代价为 `0.25 + 0.3 × 部位不同 + 0.3 × 方式不同 + 0.15 × 清浊不同`，上限 1。不在特征表中的不同音素代价为 1，仅长度记号不同则为 0.2。
- `接近度 = round(100 × (1 − 最短距离 / max(目标音素数, 识别音素数)))`，限制在 0–100，多种合法读法取最佳结果。逐音素展示对齐，并提示最值得重听的一处。

特征术语参考 [国际音标表](https://www.internationalphoneticassociation.org/IPAcharts/IPA_charts_TI/IPA_charts_TI.html)。**权重是本项目自定工程规则，不是 IPA 协会提供或认可的评分方法**；完整小型特征表见 `src/scoring.ts`。

例如目标 /kæt/，识别成 /kɛt/ 会有部分接近度，并提示练 /æ/；识别成 /kæ/ 会提示模型没有听到 /t/。模型可能听错，100 不证明发音标准。短单词分数会跳动，相同音素内部的细微音色改善不能反映在分数中。

## 前后变化与数据

仅比较同一目标、目标序列、模型版本、推理引擎、评分版本的更早记录。旧记录不回填，无法判断的记录跳过。升分只说明模型输出更接近目标，不证明能力提高。JSON 导出为 schemaVersion 2，记录总接近度、版本、逐音素对照及提示，不含原始录音。

当前不是专门训练的 GOP/发音评测模型，不能可靠评判口型、重音、节奏、自然度或普通话声调。须由懂相应发音的成人审核示范与提示，再用真实儿童录音和家长标注验证误报、漏报及分数变化方向。游戏中可先作为辅助反馈，不建议直接据此扣生命或锁住关卡。
